## Production steps

The Equinox repo has no video pipeline; Vigil's (`../../vigil/video/` — `record.ts`, `tts.py`, `captions.py`, `build.py`, `verify.sh`) is the reference and its `tts.py`/`build.py` can be reused for narration and assembly, but the MetaMask segments must be captured by hand (a wallet popup cannot be driven by the headless recorder). Minimal manual pipeline:

1. **Cards** (S1, S5, end): write them as `cards.html` in the workspace (copy Vigil's `video/cards.html` styling: dark background, monospace tables) and screenshot each at 1920×1080 (`chromium --headless --screenshot=out/cards/problem.png --window-size=1920,1080 file://…/cards.html?card=problem`).
2. **Screen takes** (S2, S3, S4, S5 terminal): OBS Studio or `ffmpeg -f x11grab -framerate 30 -video_size 1920x1080 -i :0.0 -c:v libx264 -crf 18 -pix_fmt yuv420p out/raw/s2.mkv`; browser at 100 % zoom, notifications off, the dashboard with `?poll=4000`; keep each take running past the last action so the refresh is on camera. Record S2, S3 and S5 on Thu 24 Sep (board 0 still tradeable), S4 on Fri 25 Sep after `--claim`.
3. **Narration**: one file per beat with the exact sentences above (⟨…⟩ tokens replaced from `docs/DEMO_LOG.md`), synthesized with edge-tts — `edge-tts --voice en-US-AndrewNeural --text "$(cat vo/1a.txt)" --write-media out/audio/1a.mp3` (Vigil's `tts.py` wraps this and measures the projected cut); or the user's own voice.
4. **Assembly**: trim each take to its slot (`ffmpeg -ss … -to … -i out/raw/s3.mkv -i out/audio/3a.mp3 -c:v libx264 -crf 18 -c:a aac -shortest out/seg/s3a.mp4`), cards as `ffmpeg -loop 1 -framerate 30 -i out/cards/problem.png -i out/audio/1a.mp3 -t 14 …`, then `ffmpeg -f concat -safe 0 -i list.txt -c copy out/equinox-demo.mp4`. Optional burned captions from the narration text (Vigil's `captions.py`).
5. **Verify**: `ffprobe -v error -show_entries format=duration -of csv=p=0 out/equinox-demo.mp4` → ≤ 180.0; every number spoken in S4 matches `docs/DEMO_LOG.md`; every tx hash on camera resolves on Arbiscan; no `.env` or key visible in any terminal frame (record terminals with `HISTFILE` off and never `cat .env`).
6. **Publish**: copy `equinox-demo.mp4` to the workspace `../../docs/assets/` (outside the repo, as Vigil did — the repo `.gitignore` does not exclude mp4, so do not commit it) and upload to HackQuest `demoVideo` (+ `pitchVideo`); fallback YouTube unlisted with chapters `0:00 Problem · 0:14 No IV oracle · 0:33 Live dashboard · 0:48 Parity · 1:15 Trade from MetaMask · 2:00 Real settlement · 2:19 Claim · 2:26 Honest gas · 2:43 Links`.

# contracts

Foundry project holding the Solidity side of the Equinox quant core.

- `src/interfaces/IBlackScholes.sol` — the ABI exported from the Stylus program (`cargo stylus export-abi`); do not edit by hand.
- `src/math/BlackScholesSol.sol` — control implementation with the same algorithms and operation order as the Rust crate, using PRBMath v4 for `exp`/`ln`/`sqrt`. Used for benchmarking, for tests that must run without a Stylus node, and as a fallback. Not the production pricer.
- `src/math/BsConstants.sol` — generated by `tools/reference/gen_constants.py`.
- `src/Bench.sol` — gas harness: measures a `STATICCALL` to any target and returns the gas used plus the return bytes.
- `test/BlackScholesSol.t.sol` — exact-equality tests against `test/VectorsGen.sol` (generated by `tools/reference/gen_vectors.py`).

```bash
forge test            # 12 tests
forge build           # via-IR is required (stack too deep otherwise)
```

Dependencies are vendored as plain copies in `lib/` (`forge-std`, `prb-math` v4.1.0).
